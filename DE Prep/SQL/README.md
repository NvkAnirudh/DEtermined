# SQL (Structured Query Language)

This directory contains practice problems and resources related to SQL concepts in Data Engineering.

## Overview

SQL is a standard language for storing, manipulating, and retrieving data in relational database management systems. In Data Engineering, strong SQL skills are essential for data transformation, analysis, and working with various database systems.

## Topics Covered

- Basic and Advanced SQL Queries
- Database Design and Normalization
- Indexing and Query Optimization
- Window Functions
- Common Table Expressions (CTEs)
- Stored Procedures and Functions
- Database Views
- Transactions and ACID Properties
- SQL Joins and Set Operations
- Performance Tuning

## Directory Structure

- **Easy**: Foundational concepts and beginner-level problems
- **Medium**: Intermediate problems requiring deeper understanding
- **Hard**: Advanced problems and system design challenges

## Learning Path

Start with the Easy problems to build a foundation, then progress to Medium and Hard as you become more comfortable with the concepts.
