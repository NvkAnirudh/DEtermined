# Distributed Systems

This directory contains practice problems and resources related to Distributed Systems concepts in Data Engineering.

## Overview

Distributed Systems involve multiple interconnected computers that work together as a unified system. In Data Engineering, distributed systems are essential for processing and storing large volumes of data across multiple machines to achieve scalability, fault tolerance, and high availability.

## Topics Covered

- Distributed Computing Principles
- Consensus Algorithms (Paxos, Raft)
- CAP Theorem
- Distributed Databases
- Distributed File Systems
- Microservices Architecture
- Fault Tolerance and High Availability
- Distributed Caching

## Directory Structure

- **Easy**: Foundational concepts and beginner-level problems
- **Medium**: Intermediate problems requiring deeper understanding
- **Hard**: Advanced problems and system design challenges

## Learning Path

Start with the Easy problems to build a foundation, then progress to Medium and Hard as you become more comfortable with the concepts.
