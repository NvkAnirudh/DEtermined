# Big Data

This directory contains practice problems and resources related to Big Data technologies and concepts in Data Engineering.

## Overview

Big Data refers to extremely large data sets that may be analyzed computationally to reveal patterns, trends, and associations. In the context of Data Engineering, it involves working with distributed computing systems and frameworks designed to handle volume, velocity, and variety of data.

## Topics Covered

- Hadoop Ecosystem (HDFS, MapReduce, YARN)
- Apache Spark
- Apache Kafka
- Data Lakes
- Batch vs Stream Processing
- Big Data Storage Solutions
- Distributed Computing Principles

## Directory Structure

- **Easy**: Foundational concepts and beginner-level problems
- **Medium**: Intermediate problems requiring deeper understanding
- **Hard**: Advanced problems and system design challenges

## Learning Path

Start with the Easy problems to build a foundation, then progress to Medium and Hard as you become more comfortable with the concepts.
