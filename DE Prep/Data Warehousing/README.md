# Data Warehousing

This directory contains practice problems and resources related to Data Warehousing concepts in Data Engineering.

## Overview

Data Warehousing involves designing, building, and maintaining infrastructure for storing, integrating, and analyzing large volumes of structured data from various sources to support business intelligence and decision-making processes.

## Topics Covered

- Data Warehouse Architecture (Kimball, Inmon, Data Vault)
- ETL/ELT Processes for Data Warehousing
- OLAP vs OLTP Systems
- Fact and Dimension Tables
- Slowly Changing Dimensions
- Data Marts
- Modern Data Warehouse Platforms (Snowflake, Redshift, BigQuery)

## Directory Structure

- **Easy**: Foundational concepts and beginner-level problems
- **Medium**: Intermediate problems requiring deeper understanding
- **Hard**: Advanced problems and system design challenges

## Learning Path

Start with the Easy problems to build a foundation, then progress to Medium and Hard as you become more comfortable with the concepts.
