# Data Modeling

This directory contains practice problems and resources related to Data Modeling concepts in Data Engineering.

## Overview

Data Modeling is the process of creating a conceptual representation of data structures and their relationships. It's a fundamental aspect of database design and data warehouse architecture that ensures data is stored efficiently and can be accessed effectively.

## Topics Covered

- Relational Data Modeling
- Dimensional Modeling (Star and Snowflake Schemas)
- Entity-Relationship Diagrams
- Normalization and Denormalization
- Data Vault Modeling
- Schema Design
- NoSQL Data Modeling

## Directory Structure

- **Easy**: Foundational concepts and beginner-level problems
- **Medium**: Intermediate problems requiring deeper understanding
- **Hard**: Advanced problems and system design challenges

## Learning Path

Start with the Easy problems to build a foundation, then progress to Medium and Hard as you become more comfortable with the concepts.
